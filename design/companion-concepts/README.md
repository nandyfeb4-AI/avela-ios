# Original animal concepts — review before final artwork

`animal-exploration-v1.png` is an AI-generated original concept board, not a
shipping asset. It explores fox, owl and otter. The detailed fur/feathers should
be simplified into a consistent, readable silhouette before app-size artwork
and six mood/state poses are approved. No image from this board is bundled in
the application.

Tool: built-in image generation. Prompt direction: premium, original, calm fox,
owl and otter; full-body, restrained teal/ivory/amber, readable silhouettes,
sculptural illustration for adults; no accessories, currency, obligation or
care mechanics. Review animal, simplification and personality before final art.

The original prototype/exploration files remain unchanged. The subsequent authorized artwork pass now bundles six poses for each animal
and renders them in the native app and Home Screen widgets. See
[production artwork and prompt set](PRODUCTION_ART.md). The original exploration
board remains unchanged and is not bundled.
